# Gemma AI Interface

A dark, mobile-first AI chat interface built with React, TypeScript, Vite/TanStack Start, Tailwind CSS, and supporting infrastructure.

## Public release

This repository contains a sanitized public build of the Gemma interface project. Internal App Builder workspace instructions and preview credentials are intentionally excluded.

## Development

```bash
npm install
npm run dev
```

Keep credentials in environment variables. Never commit `.env` files or OAuth/API secrets.

## Status

Prototype / active development.
